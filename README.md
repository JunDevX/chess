# Local chess game
## What is this?
This Node.js project allows you to play a local game of chess with an acquaintance (or acquaintances), without the need to register or log in to a Chess.com or Lichess.org account.

## Install and start
1. Check if Node.js is installed ()
```
npm -version
```
2. If you didn't get any output regarding the Node.js version, simply install it from nodejs.org.
3. Next, clone the repository using Git, or download it from the repository page by clicking the `Code -> Download ZIP` button.
```
git clone https://github.com/JunDevX/chess.git
```
4. Install all dependencies and start a local server. (INSTALL DEPENDENCIES FROM THE chess FOLDER)
```
npm install
```
5. Start local server.
```
npm start
```
**OR**
```
node server.js
```

## Installation with submodules
1. Check if Node.js is installed ()
```
npm -version
```
2. If you didn't get any output regarding the Node.js version, simply install it from nodejs.org.
3. Clone the repository using the GIT command
```
git clone --recursive https://github.com/JunDevX/chess.git
```
